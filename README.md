# SinkClientLibrarySampleRTSP
Subscribe to a CCTV Feed (with embedded RTSP server)

## Sample 2: Run Sink Cascade Full Set (With RTSP Server)
The Video Sink Client subscribes video channel and stream it with the built-in RTSP service. Users can consume the video data by connecting the RTSP service using media player or own application.  

### run
mvn spring-boot:run
